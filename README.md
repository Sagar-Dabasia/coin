# Bhumi Coin — Stage 1 MVP

> *"Some legends are born. Others are minted."*

Bhumi Coin is an original, fictional cryptocurrency tribute and educational project dedicated to Bhumi. Inspired by vintage European heritage houses, private country clubs, and equestrian editorial elegance.

**Important Notice:** This is a purely fictional educational demonstration. It has **no monetary value**, no blockchain transactions, no real crypto wallets, and no financial claims.

---

## Visual Identity
- **Forest Green** (`#152B24`): Primary background and rich depth
- **Ivory** (`#F4EFE4`): Refined text and soft contrast
- **Antique Gold** (`#B89858`): Regal accents, numismatic borders, 3D coin luster
- **Deep Navy** (`#1E2936`) & **Oxblood** (`#642E33`): Editorial heritage accents

---

## Features (Stage 1)
1. **Editorial Navigation**: Responsive header with wordmark, section anchors, and keyboard-accessible mobile menu.
2. **Hero Section**: Dramatic editorial typography with live 3D gold Bhumi Coin.
3. **The Origin Story**: A witty chronicle of how an afternoon conversation gave rise to an accidental sovereign standard.
4. **Interactive 3D Coin**: Built with Three.js and React Three Fiber.
   - Procedural numismatic bump/relief textures.
   - Interactive 3D rotation and inspection.
   - Working **Flip the Coin** feature with randomized imperial decrees and humorous Latin fortunes.
   - WebGL error boundary and graceful 2D static fallback.
5. **The Bhumi Society**: Private club presentation featuring the 4 founding principles and interactive honorary fellowship invitation.
6. **Footer & Disclaimer**: Elegant typography with explicit non-financial disclaimer.

## Development Setup

```bash
# Install dependencies
npm install

# Run TypeScript typecheck
npm run typecheck

# Build for production
npm run build

# Start local development server
npm run dev
```

Local dev server runs at: `http://localhost:5173/`
